# 写给 Web3 新人的加密货币交易入门：从现货、USDT 到合约交易

很多人第一次进入 Web3，最先接触到的不是智能合约、DeFi 协议、DAO 治理，而是“买币”和“交易”。

你会看到很多词：

```text
BTC
ETH
USDT
现货
交易所
币币交易
做多
做空
杠杆
保证金
合约
爆仓
止盈
止损
```

如果只看这些词，会觉得它们很乱。但其实它们可以被放进一个清晰的框架里：

```text
你交易的是什么资产？
你在哪里交易？
你用什么作为计价货币？
你是买卖资产本身，还是交易价格方向？
你有没有使用杠杆？
你能承受多大的损失？
```

这篇文章不是鼓励你炒币，也不是教你高风险交易。相反，它的目的只有一个：用 Web3 的语境，把加密货币交易里最基础的一组概念讲清楚。

先说结论：

> 新人最重要的不是学会怎么赚钱，而是先知道自己在买什么、风险在哪里、哪些东西不能碰。

尤其是合约交易，新手不要轻易碰。它看起来像放大收益，实际上也会同步放大亏损。

---

## 一、什么是“炒币”？

所谓“炒币”，最朴素的理解就是：

```text
低价买入数字货币，高价卖出，赚中间差价。
```

比如你认为 BTC 未来会涨，于是用 USDT 买入 BTC。等 BTC 价格上涨后，你再卖出 BTC，换回更多 USDT。

这个逻辑和炒股、炒房、炒外汇在形式上很像，都是围绕价格波动获利。

但加密货币市场有几个明显特点：

```text
全天 24 小时交易
全球化流动性
波动幅度大
没有传统 A 股那种涨跌停限制
资产类型复杂
项目质量差异极大
合约杠杆风险极高
```

所以它既可能带来更大的机会，也意味着更大的风险。

你可以把加密货币交易分成两类：

```text
现货交易：买卖币本身
合约交易：交易价格方向和杠杆仓位
```

现货相对直观，合约复杂得多。

---

## 二、什么是交易所？

交易所就是提供数字资产交易的平台。

它的作用类似传统金融里的证券交易所和券商系统的组合：

```text
展示交易对
展示行情
提供盘口和订单簿
撮合买卖订单
管理账户资产
记录订单和成交
提供充值、提现、划转等能力
```

在中心化交易所里，用户通常先注册账户，把资产充值到交易所账户里，然后在交易所内部买卖。

在去中心化交易所 DEX 里，用户通常通过钱包连接协议，直接和链上智能合约交互。

两者可以简单对比：

| 类型               | 交易方式     | 资产托管           | 代表形态                |
| ------------------ | ------------ | ------------------ | ----------------------- |
| 中心化交易所 CEX   | 交易所撮合   | 资产放在交易所账户 | Binance、OKX 等         |
| 去中心化交易所 DEX | 智能合约执行 | 用户钱包自托管     | Uniswap、Curve、dYdX 等 |

CEX 更像传统互联网产品，账户、订单、撮合、风控大多由平台系统完成。
DEX 更强调链上透明和钱包自托管，但用户也要承担钱包、私钥、合约风险。

对前端开发者来说，交易所页面通常包括：

```text
行情页
现货交易页
合约交易页
资产页
充值提现页
订单管理页
K 线图
盘口
成交列表
```

这些功能背后都不是普通 CRUD，而是交易系统业务状态的组合。

## 三、什么是 USDT？

USDT 是一种稳定币 Stablecoin。

稳定币的目标是让加密资产的价格尽量锚定某种稳定资产。USDT 主要锚定美元，因此很多交易场景里会把它当作美元计价单位使用。

简单理解：

```text
BTC/USDT 表示用 USDT 给 BTC 定价
ETH/USDT 表示用 USDT 给 ETH 定价
```

如果 BTC/USDT = 60,000，意思是市场认为 1 BTC 大约值 60,000 USDT。

但要注意：

> USDT 可以理解为锚定美元的稳定币，但它不等于真正的美元，也不是银行账户里的美元存款。

它是由发行方基于储备资产发行的链上代币。Tether 官方将自己描述为使用区块链技术推动法币数字化的平台；Binance Academy 对 USDT 的解释是，它是一种设计上与美元 1:1 挂钩，并由 Tether 储备支持的稳定币。([Tether](https://tether.to/?utm_source=chatgpt.com))

在交易所里，USDT 常常承担三种角色：

```text
计价单位：BTC/USDT、ETH/USDT
交易中介：先换成 USDT，再买其他币
避险资产：行情剧烈波动时，用户可能先换回 USDT
```

所以你会看到很多交易对都以 USDT 结尾。

## 四、什么是币币交易？

币币交易就是用一种数字资产兑换另一种数字资产。

比如：

```text
USDT 买 BTC
BTC 换 ETH
ETH 换 USDT
```

最常见的是用 USDT 买卖其他币：

```text
BTC/USDT
ETH/USDT
SOL/USDT
BNB/USDT
```

这里有两个概念：

```text
base asset：基础资产
quote asset：计价资产
```

以 BTC/USDT 为例：

```text
BTC 是 base asset
USDT 是 quote asset
```

意思是：用 USDT 给 BTC 定价。

从前端页面看，现货交易页通常需要处理：

```text
交易对切换
买入 / 卖出
限价单 / 市价单
可用余额
当前委托
历史委托
撤单
成交记录
```

这些就是现货交易系统的基础模块。

---

## 五、什么是主流币？

主流币一般指市场认可度较高、流动性较好、市值排名靠前的加密资产。

最典型的是：

```text
BTC
ETH
```

BTC 是最早、认知度最高的加密资产。
ETH 是以太坊网络的原生资产，也是智能合约生态的基础资产。

其他是否算主流币，不同人标准不同。有的人只认 BTC 和 ETH，有的人会把市值排名靠前、在主流交易所上市、交易深度较好的币种也算进去。

判断一个币是否相对主流，可以看几个维度：

```text
市值规模
交易量
流动性
交易所覆盖度
链上生态
开发者活跃度
真实使用场景
项目透明度
```

市值靠前不代表没有风险，但通常比极小市值项目更有流动性和市场认可度。

反过来，小市值币、土狗币、概念币、空气币，风险会高很多。价格可能短时间暴涨，也可能瞬间归零。

## 六、基础交易术语怎么理解？

下面这些词在股票、期货、加密货币里都常见，只是具体场景不同。

### 仓位

仓位指你把多少资金投入到某个资产里。

比如你总资产 10,000 USDT，其中 3,000 USDT 买了 BTC，那么 BTC 仓位就是 30%。

```text
仓位 = 某项资产投入金额 / 总资金
```

### 全仓

全仓就是把几乎全部资金都投入某个资产。

这风险很高，因为你没有留出调整空间。

### 空仓

空仓就是手里没有持有相关资产，主要持有现金或稳定币。

### 减仓

减仓就是卖掉一部分资产，降低风险暴露。

### 补仓

补仓就是在原有持仓基础上继续买入。

比如你先买 1 ETH，后来又买 1 ETH，这就是补仓。

### 止盈

止盈是价格上涨后卖出，锁定利润。

例如 BTC 从 60,000 涨到 70,000，你卖出一部分，保住盈利。

### 止损

止损是价格下跌到某个程度后卖出，防止亏损继续扩大。

止损不是坏事，但必须有逻辑。不能只是因为情绪恐慌而卖出。

### 牛市

牛市指市场整体持续上涨，情绪乐观。

### 熊市

熊市指市场整体持续下跌，情绪低迷。

### 反弹

价格下跌后出现短暂回升。

### 横盘

价格在一个区间内上下震荡，没有明显趋势。

### 跳水 / 瀑布

价格快速大幅下跌。

### 套牢

买入后价格下跌，账面亏损，短期不愿卖出。

### 解套

之前被套的资产后来涨回买入价附近，亏损消失或减少。

### 踏空

本来想等下跌再买，结果价格一路上涨，错过行情。

这些词更多是交易者描述行情和持仓状态的语言，不是精确金融模型，但你做交易产品、看用户社区、理解产品文案时会经常遇到。

## 七、做多和做空是什么？

做多 Long，就是看涨。

在现货里，做多通常就是买入资产，等价格上涨后卖出。

```text
低价买入
高价卖出
赚差价
```

比如 BTC 60,000 买入，70,000 卖出，你赚中间差价。

做空 Short，就是看跌。

传统意义上，做空是先借入资产卖出，等价格下跌后再买回来还掉，中间差价就是利润。

比如你借入 1 BTC，在 60,000 卖出。
后来 BTC 跌到 50,000，你用 50,000 买回 1 BTC 归还。
中间理论上赚 10,000。

但普通现货用户通常不能直接做空。
在加密交易所里，做空更多发生在合约交易、保证金交易或衍生品交易里。

所以你可以这样记：

```text
现货交易：主要通过买入后上涨赚钱
合约交易：可以做多，也可以做空
```

这就是为什么合约页面会有“开多”和“开空”。

---

## 八、什么是现货交易？

现货交易就是买卖资产本身。

你买 BTC/USDT，买到的是 BTC。
你卖 BTC/USDT，卖出的是 BTC，换回 USDT。

现货交易相对直观：

```text
买入 BTC：USDT 减少，BTC 增加
卖出 BTC：BTC 减少，USDT 增加
```

前端实现现货页时，最核心的是：

```text
买入时检查 USDT 余额
卖出时检查 BTC 余额
限价单需要价格和数量
市价单可能按金额或数量成交
下单成功后刷新余额和委托
撤单成功后刷新当前委托
```

现货交易最大的风险来自资产价格下跌。
但只要不是借钱买、不是杠杆买，一般不会出现强制平仓。

---

## 九、什么是合约交易？

合约交易不是直接买卖币本身，而是围绕价格方向建立仓位。

以 BTC/USDT 永续合约为例：

```text
开多：认为 BTC 会涨
开空：认为 BTC 会跌
平仓：结束已有仓位
```

你开多 BTC，并不代表你真的拿到了 BTC。
你开空 BTC，也不代表你真的卖出了真实 BTC。
你交易的是 BTC 价格变化带来的盈亏。

加密货币交易所里最常见的是永续合约 Perpetual Futures / Perpetual Swap。

永续合约和传统期货很像，但没有到期日。只要保证金满足要求，理论上可以持续持有。它通常通过资金费率机制，让合约价格尽量贴近现货市场价格。Binance Academy 对永续合约的解释也提到，它没有到期日，并通过资金费率让永续价格锚定底层现货市场。([Binance Academy](https://academy.binance.com/ka-GE/articles/what-are-perpetual-futures-contracts.amp?utm_source=chatgpt.com))

所以合约交易页通常会有：

```text
开多
开空
杠杆
保证金
全仓
逐仓
持仓
未实现盈亏
强平价
资金费率
止盈止损
计划委托
平仓
一键平仓
```

这些字段都是合约交易风险机制的一部分。

## 十、杠杆和保证金是什么？

合约交易最吸引人，也最危险的地方，就是杠杆。

杠杆的意思是：

```text
用较少的保证金，控制更大的名义仓位。
```

比如你有 100 USDT，使用 10 倍杠杆，可以开大约 1,000 USDT 的仓位。

```text
名义仓位 = 保证金 × 杠杆
```

如果价格朝你判断的方向变化，收益会被放大。
如果价格朝相反方向变化，亏损也会被放大。

保证金就是你为了维持这个仓位而放进去的风险抵押。

比如：

```text
100 USDT 保证金
10x 杠杆
1,000 USDT 名义仓位
```

如果这个 1,000 USDT 仓位亏损 50 USDT，你的保证金就少了 50%。
如果亏损继续扩大，保证金不足，就可能被强平，也就是俗称爆仓。

所以千万不要只看到：

```text
100 倍杠杆 = 收益放大 100 倍
```

你还要看到：

```text
100 倍杠杆 = 价格轻微反向波动就可能爆仓
```

---

## 十一、爆仓是什么？

爆仓，也就是强制平仓 Liquidation。

当用户亏损过大，保证金不足以维持仓位时，系统会强制关闭仓位，防止亏损继续扩大。

你可以把保证金理解成安全垫：

```text
保证金越厚，越能承受波动
保证金越薄，越容易被强平
杠杆越高，安全垫越薄
```

比如 100 倍杠杆下，价格只要朝不利方向波动很小一段，就可能触发强平。

前端页面里常见的强平相关字段包括：

```text
强平价
保证金率
风险率
标记价格
维持保证金
追加保证金
```

如果你做交易系统前端，这些字段必须谨慎展示。它们不是装饰信息，而是用户风险控制的核心。

---

## 十二、什么是全仓和逐仓？

合约交易里常见两种保证金模式。

### 逐仓 Isolated

逐仓就是每个仓位单独分配保证金。

这个仓位亏损时，主要亏这个仓位分配的保证金。

优点是风险隔离。
缺点是更容易被强平。

### 全仓 Cross

全仓就是账户里的可用保证金可以共同支撑仓位。

如果某个仓位亏损，系统可能使用账户里其他可用保证金来维持它不被强平。

优点是强平可能更远。
缺点是风险会扩散，极端情况下可能影响整个合约账户。

所以全仓/逐仓不是简单 UI 选项，而是风险模式。

---

## 十三、什么是计划委托、止盈止损？

### 计划委托

计划委托是条件触发订单。

比如：

```text
当 BTC 突破 70,000 时，触发市价开多。
```

它不是立刻进入订单簿，而是先等待触发条件。

常见字段：

```text
触发价
委托价
方向
数量
订单类型
状态
撤销
```

### 止盈止损

止盈止损是围绕持仓设置的风险控制。

```text
止盈：涨到目标价自动平仓获利
止损：跌到风险价自动平仓止损
```

在合约交易里，止盈止损非常重要，因为杠杆会放大波动，不能只靠人工盯盘。

---

## 十四、为什么说新手不要玩合约？

因为合约交易同时具备三个特点：

```text
高波动
高杠杆
强平机制
```

现货亏损时，你至少还持有资产。
合约亏损时，如果保证金不够，仓位会被系统强制平掉。

尤其是高倍杠杆，会让容错空间极小。

很多人以为合约是通向财富自由的捷径，其实更多时候，它只是让你更快暴露在风险里。

所以对新手来说，最重要的不是学会开 50 倍、100 倍杠杆，而是先理解：

```text
自己是否真的理解仓位
是否理解保证金
是否理解强平
是否有止损纪律
是否能承受本金损失
```

如果这些都不理解，合约不是工具，而是赌博放大器。

## 十五、从 Web3 开发者角度看交易系统

如果你是 Web3 前端或交易平台开发者，这些概念最后都会落到页面和接口上。

### 现货交易页

你需要理解：

```text
交易对
买入 / 卖出
限价 / 市价
余额
盘口
成交
当前委托
历史委托
撤单
```

业务逻辑是：

```text
买入看 quote 余额，例如 USDT
卖出看 base 余额，例如 BTC
下单成功刷新余额和委托
撤单成功刷新当前委托和余额
```

### 合约交易页

你需要理解：

```text
开多 / 开空
杠杆
保证金
全仓 / 逐仓
持仓
浮动盈亏
强平价
止盈止损
计划委托
平仓
一键平仓
```

业务逻辑是：

```text
开仓影响保证金、持仓、委托
平仓影响持仓、钱包、历史记录
调整杠杆影响可开数量和强平风险
撤单可能释放冻结保证金
止盈止损会影响持仓或计划委托
```

这就是为什么交易类前端比普通后台复杂。
它不是简单的表单提交，而是一套资产、订单、行情、风控状态的联动系统。

## 十六、最后总结

加密货币交易不是只有“买涨卖跌”这么简单。

它至少包含三层知识：

```text
第一层：资产知识
BTC、ETH、USDT、稳定币、主流币、小市值币

第二层：交易机制
交易所、交易对、现货、盘口、订单簿、限价单、市价单

第三层：衍生品和风险
合约、做多、做空、杠杆、保证金、强平、止盈止损、计划委托
```

如果你是普通新人，最重要的是先理解风险，不要上来就玩高杠杆合约。

如果你是 Web3 从业者，最重要的是理解这些概念在交易系统里的含义。因为页面上的每个字段、每个按钮、每个接口参数，都对应真实的交易行为和风险状态。

一句话总结：

**现货交易是在买卖币本身，合约交易是在交易价格方向；USDT 是常见的稳定币计价单位，杠杆和保证金会放大收益，也会放大亏损。对新人来说，理解风险永远比追求收益更重要。**
