# Uniswap 流动性池入门：如何通过提供流动性赚取交易手续费

在 Uniswap 上，用户不仅可以兑换 Token，也可以成为流动性提供者，也就是 Liquidity Provider，简称 LP。

当你把两种 Token 存入某个交易池后，其他用户在这个池子里交易时会支付手续费，而你可以按照自己提供的流动性占比获得其中一部分手续费。

这听起来像是“让资产自己工作”，但它并不是没有风险的被动收益。提供流动性涉及无常损失、价格波动、智能合约风险和 Token 本身的风险。

这篇文章会从基础概念开始，讲清楚 Uniswap 流动性池是什么、如何选择池子、TVL / Volume / APR 这些指标怎么看、V2 / V3 / V4 有什么区别，以及如何一步步添加流动性。

## 一、Uniswap 是什么

Uniswap 是一个去中心化交易所，运行在 Ethereum 以及多个 Layer 2 网络上。

和传统交易所不同，Uniswap 不使用订单簿。

传统订单簿里有买单和卖单，交易需要买卖双方价格匹配。

Uniswap 使用的是 AMM，也就是 Automated Market Maker，自动做市商机制。

在 Uniswap 中，每一个交易对背后都有一个流动性池。

例如：

```txt
ETH / USDC
```

这个交易对背后就有一个智能合约池子，里面同时存放 ETH 和 USDC。

用户想用 ETH 换 USDC，或者用 USDC 换 ETH，都可以直接和这个池子交互。

## 二、什么是流动性池

流动性池是一个持有两种或多种资产的智能合约。

以 ETH / USDC 池为例，池子里会有：

ETH；

USDC。

当交易者来兑换时，智能合约会根据池内资产比例自动计算价格，并执行交易。

如果你把自己的 ETH 和 USDC 存入这个池子，你就成为了 LP。

作为回报，你可以获得这个池子产生的部分交易手续费。

简单理解：

```txt
交易者使用池子完成 swap
  ↓
交易者支付手续费
  ↓
手续费分给流动性提供者
```

这就是 LP 收益的基本来源。

## 三、提供流动性不是简单存款

很多新手会把提供流动性理解成“存钱赚利息”。

这个理解不准确。

LP 更像是把资产拿出来做市。

你的资产会随着交易不断在两种 Token 之间重新分配。

如果价格发生较大变化，你最终持有的 Token 比例也会变化。

因此，LP 收益不是固定利息，也不是无风险收益。

它更像是一种带市场风险的交易策略。

## 四、最大的风险：无常损失

提供流动性时最重要的风险是 Impermanent Loss，中文通常叫无常损失。

当池子中两种 Token 的价格走势发生明显分化时，池子会自动调整你持有的资产比例。

结果可能是：

你持有更多表现较差的 Token；

你持有更少上涨较多的 Token。

举个简化例子。

你向 ETH / USDC 池提供流动性。

如果 ETH 大涨，池子会逐渐卖出 ETH、增加 USDC。

最终你可能发现，自己持有的 ETH 变少了。

虽然你赚到了手续费，但如果 ETH 涨得很多，手续费可能无法弥补你相比“单纯持有 ETH + USDC”少赚的部分。

这就是无常损失。

它不一定是永久损失。如果价格回到原来的相对水平，损失可能减少。但如果你在价格偏离时退出，就会实际承担这部分损失。

## 五、其他风险

除了无常损失，还需要注意几类风险。

第一是市场波动风险。

Token 价格可能剧烈变化，尤其是小市值 Token。

第二是智能合约风险。

Uniswap 本身经过长期使用，但 DeFi 交互始终存在合约漏洞、前端风险、签名风险等问题。

第三是 Token 风险。

如果你选择的是不熟悉的小币种，可能遇到项目方撤流动性、合约黑名单、恶意税费、价格操纵等问题。

第四是流动性风险。

某些池子 TVL 很小，看似 APR 很高，但交易量不稳定，进出成本也可能很高。

所以，LP 不是保本理财，而是高级 DeFi 策略。

## 六、如何连接钱包

进入 Uniswap 前，先确认访问的是正确网址：

```txt
app.uniswap.org
```

进入页面后，点击右上角的 Connect。

选择你使用的钱包，例如：

MetaMask；

Coinbase Wallet；

WalletConnect；

Rabby；

其他支持的钱包。

确认连接后，页面右上角会显示你的地址。

还要确认当前网络是否正确。

Uniswap 支持 Ethereum 主网和多个 Layer 2 网络，例如 Arbitrum、Optimism、Base 等。

如果你要在 Arbitrum 上提供流动性，钱包也必须切换到 Arbitrum 网络。

## 七、如何找到流动性池

在 Uniswap 页面中，进入 Explore，然后打开 Pools。

这里会看到一个池子列表。

每一行通常代表一个交易对，例如：

```txt
ETH / USDC V3 0.05%
```

这表示：

交易对是 ETH / USDC；

版本是 Uniswap V3；

手续费等级是 0.05%。

表格里通常还会显示：

TVL；

APR；

24 小时交易量；

30 日交易量；

手续费收入；

Volume / TVL 等指标。

这些数据可以帮助你判断一个池子是否值得加入。

## 八、TVL 是什么

TVL 是 Total Value Locked，也就是总锁仓价值。

它表示这个池子中目前有多少资产。

TVL 越高，通常说明池子越深，交易者在里面交易时滑点更小。

但对 LP 来说，TVL 高并不一定代表收益高。

因为手续费是所有 LP 一起分的。

如果池子 TVL 很大，但交易量不高，你分到的手续费可能并不多。

所以不要只看 TVL。

## 九、Volume 是什么

Volume 是交易量。

它表示一定时间内有多少交易从这个池子经过。

LP 的手续费主要来自交易量。

如果池子每天交易量很高，那么手续费来源就更充足。

一个理想的池子通常需要：

有较高 TVL；

也有持续健康的交易量。

如果 TVL 高但交易量很低，资金利用率不高。

如果交易量高但 TVL 很低，可能存在较高波动和风险。

## 十、APR 是什么

APR 是预估年化收益率。

Uniswap 页面中的 APR 通常根据最近一段时间的手续费收入估算。

它不是固定收益，也不是承诺收益。

如果今天交易量很大，APR 可能看起来很高。

如果明天市场冷清，APR 就会下降。

所以 APR 只能作为参考，不能当成稳定收益。

看到特别高的 APR 时，更要问几个问题：

这个池子交易量是否持续？

Token 是否安全？

TVL 是否太低？

是否只是短期异常数据？

是否存在极高无常损失风险？

## 十一、手续费等级怎么理解

Uniswap 中，不同池子可能有不同手续费等级。

常见费率包括：

```txt
0.01%
0.05%
0.3%
1%
```

低费率通常适合稳定币或高度相关资产。

例如 USDC / USDT 这种价格非常接近的交易对，交易者希望手续费低、滑点低，所以低费率池更常见。

中等费率适合主流波动资产。

例如 ETH / USDC、WBTC / ETH 等。

高费率更适合波动较大、风险较高或交易不那么频繁的资产。

新手通常更适合从蓝筹资产和主流费率池开始，而不是追逐小币种高 APR。

## 十二、Uniswap V2、V3、V4 有什么区别

Uniswap 目前有多个版本，不同版本的 LP 机制差异很大。

### 1. Uniswap V2

V2 是比较经典的模型。

提供流动性时，通常需要按照 50 / 50 的价值比例存入两种 Token。

你的流动性会覆盖整个价格区间。

优点是简单、被动、容易理解。

缺点是资金效率较低。

因为你的资金被分散到所有可能价格范围，即使当前价格只在一个小范围内交易，你的资金也不会集中在那里。

### 2. Uniswap V3

V3 引入了集中流动性。

LP 可以自己选择价格区间。

只有当市场价格位于你设置的区间内，你的资金才会参与做市并赚取手续费。

优点是资金效率更高，潜在手续费收益更高。

缺点是需要更多管理。

如果价格离开你的区间，你的流动性就会 out of range，不再赚取手续费。

此外，V3 的 LP 头寸不是普通 ERC20 LP Token，而是 NFT 形式的 position。

### 3. Uniswap V4

V4 可以理解为在 V3 的基础上加入更多可扩展能力。

它引入了 hooks，也就是可以定制池子行为的附加逻辑。

Hooks 可以实现很多功能，例如：

动态手续费；

内置限价单；

自动再平衡；

特殊交易逻辑；

自定义结算逻辑。

V4 更灵活，也可能更高效。

但 hooks 也意味着更复杂的智能合约逻辑。

因此，使用 V4 池子时，需要理解具体 hook 的风险。

## 十三、示例：Arbitrum 上的 ETH / USDC V3 池

假设我们选择一个具体例子：

```txt
ETH / USDC
Uniswap V3
Arbitrum
0.05% fee tier
```

这个池子通常属于主流交易对。

ETH 和 USDC 都是高流动性资产，交易需求强，适合作为教学示例。

如果页面显示：

TVL 约 7500 万美元；

APR 约 56% 到 57%；

24 小时交易量约 2.33 亿美元；

24 小时手续费约 11.6 万美元。

这些数据说明：

这个池子规模很大；

交易非常活跃；

手续费来源充足；

Volume / TVL 比例较高；

APR 来自最近较强的交易活动。

但仍然要注意，这些数据只是某个时点的快照。

如果市场变冷，交易量下降，APR 也会下降。

## 十四、确认网络和桥接资产

如果这个池子在 Arbitrum 上，你的钱包也必须切到 Arbitrum。

如果你的 ETH 或 USDC 还在 Ethereum 主网，就不能直接用于 Arbitrum 池子。

你需要先跨链。

在 Uniswap 中，可以通过 Swap 或 Bridge 功能把资产从主网转到 Arbitrum。

流程大致是：

选择源网络；

选择目标网络 Arbitrum；

选择 Token 和金额；

确认桥接；

等待资产到达 Arbitrum。

资产到账后，才能在 Arbitrum 池子里添加流动性。

## 十五、查看池子详情页

点击目标池子后，会进入池子详情页。

这里通常会显示：

价格走势图；

APR；

TVL；

24 小时交易量；

池内 Token 数量；

手续费数据；

当前价格；

历史表现。

这相当于池子的 X 光片。

如果你看到一个池子：

TVL 很低；

交易量很小；

Token 名字陌生；

价格波动异常；

APR 高得离谱；

池子刚创建不久。

那就需要非常谨慎。

对于新手来说，优先选择自己理解的 Token 和主流池子。

## 十六、添加流动性第一步：进入 Add Liquidity

在池子详情页点击 Add Liquidity。

如果你是从已有池子进入，交易对和费率通常已经自动填好。

例如：

```txt
ETH / USDC
0.05%
Uniswap V3
Arbitrum
```

如果你只是加入已有池子，一般不需要修改 Token 和费率。

确认无误后，点击 Continue。

## 十七、设置 V3 价格区间

进入 V3 头寸创建页面后，你需要设置价格区间。

这正是 V3 和 V2 最大的区别。

你会看到一个价格图表，以及一个彩色区间带。

这个区间代表你的流动性在哪些价格范围内生效。

有两种主要方式：

Full Range；

Custom Range。

### 1. Full Range

Full Range 类似 V2。

你的流动性覆盖所有价格范围。

优点是更被动，不容易 out of range。

缺点是资金效率较低，手续费收益可能较低。

### 2. Custom Range

Custom Range 允许你选择具体价格范围。

例如：

```txt
最低价格：2500 USDC / ETH
最高价格：3800 USDC / ETH
```

假设当前 ETH 价格在这个范围中间，那么你的流动性会在这个区间内参与交易。

只要 ETH 价格保持在这个范围内，你就可以赚取手续费。

如果价格离开区间，你就不再赚取手续费。

## 十八、窄区间和宽区间怎么选

价格区间越窄，资金越集中。

这可能带来更高的手续费收入，因为你的资金在当前价格附近发挥更大作用。

但窄区间也更容易 out of range。

一旦价格超出范围，你的资金就停止赚取手续费，并逐渐变成其中一种 Token。

价格区间越宽，越不容易 out of range。

但资金效率较低，单位资金赚取的手续费可能更少。

简单理解：

```txt
窄区间：收益潜力高，管理要求高
宽区间：更稳妥，收益效率较低
Full Range：最被动，资金效率最低
```

新手可以从较宽区间开始，先理解机制，再逐步尝试更主动的策略。

## 十九、系统会自动计算两种 Token 比例

设置价格区间后，进入 Deposit Tokens 部分。

你输入想投入的金额，Uniswap 会根据当前价格和你设置的价格区间，自动计算需要多少 ETH 和多少 USDC。

V3 不一定永远是 50 / 50。

如果你的价格区间围绕当前价格，通常需要同时投入两种 Token。

如果你的区间完全在当前价格上方或下方，可能只需要其中一种 Token。

这叫单边流动性或 out-of-range liquidity。

但即使一开始只投入一种 Token，随着市场价格进入你的区间，你的头寸也会逐渐转换成两种资产。

## 二十、确认金额和风险

输入金额前，要确认自己愿意承担这部分资产风险。

检查：

钱包是否有足够 ETH 和 USDC；

网络是否正确；

金额是否符合你的风险承受能力；

价格区间是否合理；

是否理解 out of range 风险；

是否接受无常损失；

是否有足够 ETH 支付 Gas。

不要把全部资金一次性放入 LP。

尤其是 V3 头寸，需要定期管理。

## 二十一、授权和确认交易

当你点击 Preview 或 Add Liquidity 时，钱包通常会弹出两类请求。

第一类是 Token Approve。

这是授权 Uniswap 合约使用你的 Token。

如果你是第一次提供某种 Token 的流动性，通常需要先 approve。

第二类是 Add Liquidity 交易。

这是实际把 Token 存入池子的链上交易。

确认前，需要检查：

Token 是否正确；

数量是否正确；

合约地址是否可信；

网络是否正确；

Gas 费用是否合理；

是否为官方 Uniswap 页面。

确认交易后，等待链上执行完成。

交易成功后，你就正式成为该池子的流动性提供者。

## 二十二、如何查看你的 LP 头寸

添加成功后，可以在 Pools 或 Positions 页面看到你的头寸。

V3 头寸通常会显示：

交易对；

费率；

价格区间；

当前是否 in range；

持有多少 ETH；

持有多少 USDC；

已赚取手续费；

当前头寸价值。

如果显示 in range，说明当前价格在你的区间内，你正在赚取手续费。

如果显示 out of range，说明价格已经离开区间，你暂时不赚取手续费。

## 二十三、如何领取手续费

V3 的手续费不会自动回到钱包。

你需要进入对应 position 页面，点击 Collect。

Collect 会把已经累积的手续费领取到你的钱包中。

你也可以选择关闭头寸。

关闭头寸时，你会撤回当前头寸中的 Token，并领取累计手续费。

需要注意的是，退出时你拿回的两种 Token 比例可能已经和存入时不同。

这是正常现象，因为池子会随着价格变化不断调整资产比例。

## 二十四、如何选择适合自己的池子

选择池子时，不要只看 APR。

更合理的做法是综合看：

Token 质量；

TVL；

交易量；

APR；

手续费等级；

网络；

价格波动；

是否容易管理；

是否理解该资产；

是否有无常损失风险。

对于新手来说，更适合从主流资产池开始，例如 ETH / USDC、ETH / WBTC 等。

不要因为某个小币池 APR 很高就直接投入。

高 APR 往往伴随高风险。

## 二十五、LP 策略的核心思路

提供流动性本质上是在做市。

你需要判断：

这个交易对未来是否会有持续交易量；

这两个 Token 是否值得长期持有；

价格是否会频繁离开你的区间；

手续费能否覆盖无常损失；

你是否愿意定期调整区间；

你是否能接受资产比例变化。

如果你不想频繁管理，可以选择更宽区间或 V2 / full range。

如果你愿意主动管理，可以选择更窄区间提高资金效率。

如果你完全不了解无常损失，不建议一开始投入太多资金。

## 二十六、V3 LP 的常见错误

### 1. 只看 APR

APR 是动态的，不是保证收益。

### 2. 区间设置太窄

新手常常为了高收益设置很窄区间，结果很快 out of range。

### 3. 不理解资产转换

价格变化后，头寸会逐渐变成其中一种 Token。

这不是系统错误，而是 AMM 机制的一部分。

### 4. 忽略 Gas 成本

频繁调整区间、领取手续费和重新部署头寸都需要 Gas。

在主网上尤其明显。

### 5. 选择不熟悉的小币

小币池可能 APR 高，但也可能流动性差、波动大、风险高。

## 二十七、总结

Uniswap 流动性池让普通用户也可以成为市场做市者。

你把资产存入池子，为交易者提供流动性，并获得交易手续费分成。

但 LP 并不是无风险收益。

你需要理解无常损失、价格波动、智能合约风险和 Token 风险。

在选择池子时，应综合查看 TVL、Volume、APR 和手续费等级，而不是只追逐最高 APR。

Uniswap V2 更简单，资金覆盖全价格区间，适合被动策略。

Uniswap V3 引入集中流动性，资金效率更高，但需要设置价格区间，也需要更多管理。

Uniswap V4 在 V3 基础上加入 hooks，带来更强的可定制能力，但智能合约复杂度也更高。

如果你是新手，可以从主流资产、主流网络和较宽价格区间开始，小额尝试，先理解机制，再逐步优化策略。

提供流动性可以成为 DeFi 中重要的收益方式，但前提是你知道自己在承担什么风险。
