# 多方计算 MPC 是什么？用“计算平均工资”讲清楚

在隐私计算领域，有一个非常重要的概念叫 **多方计算**，英文是 **Multi-Party Computation**，简称 **MPC**。

它解决的是一个很现实的问题：

> 多个人想一起计算一个结果，但每个人都不想暴露自己的原始数据。

听起来有点矛盾：既要一起算，又不能把数据交出来。MPC 的价值就在这里，它允许多个参与方在保护各自隐私的前提下，共同完成计算。

为了理解 MPC，我们可以从一个很简单的例子开始：**计算一群人的平均工资**。

---

## 一、问题：想知道平均工资，但不想公开自己的工资

假设有 4 个人，分别叫：

- P1
- P2
- P3
- P4

他们在同一个行业工作，现在想知道这个行业里大家的平均工资。

每个人的工资分别是：

- P1 的工资是 a
- P2 的工资是 b
- P3 的工资是 c
- P4 的工资是 d

他们想计算：

```text
(a + b + c + d) / 4
```

但是问题来了：
每个人都不想直接告诉别人自己赚多少钱。

如果大家直接公开工资，当然可以算出平均值，但隐私就没了。

那么有没有办法做到：

> 大家最后都知道平均工资，但没有人知道别人具体工资是多少？

答案就是：可以，用多方计算。

---

## 二、核心思路：把自己的工资拆成几份随机数

MPC 的关键思想之一是：**不要直接暴露原始数据，而是把原始数据拆成多份随机数据。**

比如 P1 的工资是 a。

P1 不直接告诉别人 a 是多少，而是随机选出 4 个数字：

```text
a1, a2, a3, a4
```

只要求这 4 个数加起来等于 a：

```text
a1 + a2 + a3 + a4 = a
```

也就是说，P1 把自己的工资 a 拆成了 4 份。

然后他这样分发：

- 把 a1 留给自己；
- 把 a2 私下发给 P2；
- 把 a3 私下发给 P3；
- 把 a4 私下发给 P4。

这里最重要的一点是：

> 单独看到其中一个随机数，无法知道 P1 的真实工资是多少。

比如 P4 只拿到了 a4。
但是 a4 本身只是一个随机数，P4 不知道 a1、a2、a3 是多少，所以他无法推出 a。

---

## 三、每个人都做同样的事情

接下来，其他人也用同样的方法拆分自己的工资。

P2 的工资是 b，他随机选出：

```text
b1, b2, b3, b4
```

满足：

```text
b1 + b2 + b3 + b4 = b
```

然后把这 4 份分别发给 P1、P2、P3、P4。

P3 的工资是 c，他随机选出：

```text
c1, c2, c3, c4
```

满足：

```text
c1 + c2 + c3 + c4 = c
```

P4 的工资是 d，他随机选出：

```text
d1, d2, d3, d4
```

满足：

```text
d1 + d2 + d3 + d4 = d
```

最后，就形成了一个表：

```text
          P1拿到   P2拿到   P3拿到   P4拿到
P1工资a     a1      a2      a3      a4
P2工资b     b1      b2      b3      b4
P3工资c     c1      c2      c3      c4
P4工资d     d1      d2      d3      d4
```

每一行加起来，等于对应参与者的工资。

也就是：

```text
a1 + a2 + a3 + a4 = a
b1 + b2 + b3 + b4 = b
c1 + c2 + c3 + c4 = c
d1 + d2 + d3 + d4 = d
```

---

## 四、每个人只计算自己手里那一列

现在，每个人手里都有 4 个数字。

比如 P4 手里有：

```text
a4, b4, c4, d4
```

P4 要做的事情很简单：
把自己收到的这些数字加起来：

```text
S4 = a4 + b4 + c4 + d4
```

同理：

P1 计算：

```text
S1 = a1 + b1 + c1 + d1
```

P2 计算：

```text
S2 = a2 + b2 + c2 + d2
```

P3 计算：

```text
S3 = a3 + b3 + c3 + d3
```

然后大家把自己的列求和结果公开出来：

```text
S1, S2, S3, S4
```

注意，这里公开的不是工资，也不是工资的某一份，而是每个人手中那一列随机数的总和。

---

## 五、为什么这样能算出总工资？

现在大家把这 4 个公开的结果加起来：

```text
S1 + S2 + S3 + S4
```

展开来看：

```text
S1 = a1 + b1 + c1 + d1
S2 = a2 + b2 + c2 + d2
S3 = a3 + b3 + c3 + d3
S4 = a4 + b4 + c4 + d4
```

所以：

```text
S1 + S2 + S3 + S4
= (a1 + a2 + a3 + a4)
+ (b1 + b2 + b3 + b4)
+ (c1 + c2 + c3 + c4)
+ (d1 + d2 + d3 + d4)
```

而每一行的和刚好等于每个人的工资：

```text
a1 + a2 + a3 + a4 = a
b1 + b2 + b3 + b4 = b
c1 + c2 + c3 + c4 = c
d1 + d2 + d3 + d4 = d
```

所以最终得到：

```text
S1 + S2 + S3 + S4 = a + b + c + d
```

这就是所有人的工资总和。

再除以 4，就得到了平均工资：

```text
平均工资 = (a + b + c + d) / 4
```

---

## 六、为什么这个过程保护了隐私？

关键在于：每个人的工资都被拆成了多个随机数。

别人只看到其中一部分随机数，无法推出原始工资。

比如 P4 收到了 P1 发来的 a4。
但是 a4 只是 a 的一个随机片段，P4 并不知道 a1、a2、a3 是多少，所以无法知道 P1 的工资 a。

换句话说：

> 每个参与方看到的都只是随机片段，而不是别人的完整数据。

最后大家公开的 S1、S2、S3、S4，也只是列求和结果，不是任何一个人的工资。

因此，这个协议实现了两个目标：

1. 算出了平均工资；
2. 没有暴露任何人的具体工资。

这就是 MPC 的基本思想。

---

## 七、MPC 的本质是什么？

从这个例子可以看出，MPC 的基本流程通常是：

1. **输入数据秘密共享**
   每个人把自己的原始数据拆成多个随机份额，分发给其他参与方。

2. **本地计算**
   每个参与方只对自己拿到的随机份额进行计算。

3. **公开中间结果或最终结果**
   只公开经过处理后的结果，而不是原始数据。

4. **恢复最终计算结果**
   大家根据公开信息还原出最终结果，比如总和、平均值、统计结果等。

所以，MPC 可以简单理解为：

> 在不暴露各自原始数据的情况下，多方共同完成一次计算。

---

## 八、MPC 有什么实际用途？

MPC 不只是一个数学游戏，它在现实世界中有很多应用。

### 1. 隐私统计

比如多家公司想统计行业平均工资、平均销售额、用户增长率，但不想暴露自己的商业数据。

MPC 可以让它们得到整体统计结果，而不泄露单个公司的数据。

### 2. 金融风控

多家银行或金融机构可以联合计算风险模型，但不直接共享用户隐私数据。

这样既能提升风控能力，又能保护客户信息。

### 3. 医疗数据分析

不同医院可以联合分析病例数据，训练模型或计算统计结果，但不泄露患者隐私。

这对于医疗研究非常重要。

### 4. 区块链私钥管理

在 Web3 和区块链领域，MPC 也常用于钱包私钥管理。

传统钱包通常由一个私钥控制资产，而 MPC 钱包可以把私钥控制权拆分给多个参与方或多个设备。这样即使某一部分泄露，也不一定能直接控制资产。

### 5. 企业数据协作

不同企业之间经常有数据合作需求，但直接共享数据存在合规和商业风险。

MPC 可以让企业“数据可用不可见”，即数据参与计算，但原始数据不暴露。

---

## 九、MPC 和普通加密有什么区别？

普通加密通常解决的是“数据传输和存储时不被别人看见”的问题。

比如你把文件加密后发给别人，别人拿到密钥才能解密。

而 MPC 解决的是另一个更复杂的问题：

> 数据不解密、不公开，也能参与计算。

这就是 MPC 的特殊之处。

普通加密更像是把数据锁进保险箱。
MPC 更像是几个人都不打开自己的保险箱，却能一起算出一个共同结果。

---

## 十、总结

多方计算 MPC 的核心思想可以用一句话概括：

> 多个参与方在不暴露各自原始数据的情况下，共同计算出一个结果。

在平均工资的例子中，每个人都把自己的工资拆成多个随机份额，然后分发给其他人。每个人只计算自己收到的随机数总和，最后大家公开这些总和，就可以算出所有人的工资总和和平均工资。

整个过程中，没有人需要公开自己的真实工资。

这就是 MPC 最重要的价值：

- 数据可以参与计算；
- 原始数据不需要暴露；
- 多方可以协作；
- 隐私可以得到保护。

在未来，随着隐私计算、金融科技、医疗数据、区块链和人工智能的发展，MPC 会越来越重要。因为很多时候，真正有价值的不是某一个人的数据，而是多个参与方的数据共同计算出的结果。

而 MPC 正是让这种协作变得安全、可信和可行的关键技术。
